If this screen does not go away within a few seconds, the app did not start. On Hostinger, check these:

  1. Files from an earlier upload are still in public_html, especially an old .htaccess. Delete everything in public_html, then extract jaqa-web.zip again.
  2. The assets folder must sit in public_html, next to index.html.
  3. Git deployment is switched off in hPanel. If it is on, it replaces your upload.
  4. Clear the website cache in hPanel. If the Hostinger CDN is on, purge it and turn off any HTML or JS minification.
  5. Reload the page with Ctrl+Shift+R (on a Mac, Cmd+Shift+R).
