# JAQA web — Hostinger upload package

`jaqa-web.zip` is the whole JAQA workspace, ready to upload. It is generated by `npm run build` from `dist/` and CI checks that it is up to date. It contains:

| File | What it is |
|---|---|
| `index.html` | The complete workspace: one self-contained HTML file with inlined CSS and JS, and no external fonts or CDNs. |
| `.htaccess` | Hidden file. Security headers, a strict Content-Security-Policy, the HTTPS redirect, no directory listing, and a block on dotfiles. |
| `global-risk/`, `finance-risk/`, `insurance-reinsurance/`, `procurement-bids/` | Optional section pages: the same app, opening on that section. |

## Download

**GitHub → Code → `release/` → `jaqa-web.zip` → Download raw file** (the ⤓ button).

## Upload to Hostinger (File Manager)

1. **Turn off Git auto-deploy, if it is set up.** In hPanel → **Websites → Manage → Advanced → Git**, disable Auto Deployment or delete the repository entry. Otherwise the next Git deploy replaces your upload.
2. Open **Files → File Manager → `public_html/`** and delete what is there. That includes `default.php` and any old `index.php` or `index.html`.
3. Click **Upload**, choose `jaqa-web.zip`, and wait for it to finish.
4. Right-click `jaqa-web.zip` → **Extract**. Set the target folder to `public_html/` itself, not a new sub-folder.
5. Delete `jaqa-web.zip` from `public_html/`.
6. Check the result. `public_html/` must directly contain `index.html` and `.htaccess`; turn on *Show hidden files* to see `.htaccess`. If they ended up in `public_html/jaqa-web/`, move them up one level, or you will get **403 Forbidden**.
7. In **Security → SSL**, make sure SSL is active.
8. Open `https://jaqa.life/`.

Permissions should be `755` for folders and `644` for files; these are Hostinger's defaults.

## Quick check after upload

- `https://jaqa.life/` loads the Situation Room.
- `https://jaqa.life/.htaccess` returns 403.
- DevTools → Network: loading the page makes no requests other than `index.html`.

Updating later: download the new `jaqa-web.zip` and repeat steps 2–5.
